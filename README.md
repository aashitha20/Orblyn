# Orblyn - A Universe for Your Thoughts

An AI-resistant, ADHD-friendly learning experience built through vibe coding.

Orblyn is a focused learning interface designed to reduce anxiety, increase clarity, and support active learning. Built as my first vibe-coded project, it helped me deeply understand structured prompting, UX thinking, and AI-driven workflows.

> https://orblyn.lovable.app

Orblyn solves this by creating a **structured, calm, distraction-free flow**.

## Core Features

* **AI-Resistance System**
  Structured prompts to prevent passive answer consumption

* **ADHD-Friendly UI**

  * Minimal interface
  * Clear progress visibility
  * Reduced cognitive overload
  * Focus-driven navigation

* **Anxiety-Reducing Progress Design**
  Predictable module structure
  Clear “where am I?” indicators
  Completion reinforcement

## Design Philosophy

* Calm visual hierarchy
* Reduced decision fatigue
* One clear action per screen
* Intentional navigation

## Built With

* Structured Prompt Engineering
* UX-first Architecture

## What I Learned

This project gave me:

* Deep understanding of prompt structuring
* UX system thinking
* Designing for neurodivergent users
* Building product logic before visuals
